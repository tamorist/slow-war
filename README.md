# The Slow War — Deterministic Climate Casualty Counter

Visualizes future deaths "locked in" by CO₂ emissions, based on the 1,000-ton rule (≈ 1 future death per 1,000 t of CO₂).

- `index.html` — story page for a general audience
- `simulator.html` — detailed simulator
- `my-day.html` — personal simulator (your day, at scale; food impacts beyond carbon)

All figures are model-based approximations. See the notes on each page for sources and caveats.

---

CO₂排出によって「確定した未来の犠牲者」を、1,000トン・ルール（CO₂ 1,000 t ≒ 将来の死者1人）にもとづいて可視化するサイトです。数値はすべて推計モデルによる概算です。出典と注意点は各ページの注記を参照してください。
